# 🃏 میز ورق — مینی‌اپ تلگرام حکم و شلم

مینی‌اپ کامل تلگرام برای دو بازی کارتی ایرانی **حکم** و **شلم**، با بازی آنلاین بین دوستان، ربات‌های سه‌سطحی، موسیقی آرام، افکت «بُرش» و طراحی فارسی راست‌چین مخصوص موبایل.

---

## ✨ قابلیت‌ها

| بخش | توضیح |
|---|---|
| 🎮 بازی‌ها | حکم کلاسیک ۴ نفره + شلم (بید، خاک، ۱۶۵ امتیاز) — دو موتور کاملاً جدا |
| 👥 آنلاین | ساخت میز، کد ۶ حرفی، لینک دعوت مستقیم، انتخاب صندلی/تیم، اتصال مجدد خودکار |
| 🤖 ربات | آسان (تقریباً تصادفی) / متوسط (قواعد هوشمند) / سخت (حافظه کارت، تشخیص خال تمام‌شده، کشیدن حکم) |
| 🔊 صدا | موسیقی پس‌زمینه آرام (حال‌وهوای شور، سنتورگونه) + افکت پخش، انداختن، جمع‌شدن، و **بُرش** با لرزش و ترک خوردن میز |
| 📱 تلگرام | ورود امن با initData، دکمه Back، لرزش (Haptic)، Menu Button، تأیید خروج، تمام‌صفحه |
| ⏱️ بازی روان | تایمر نوبت ۴۵ ثانیه، اگر کسی قطع شود ربات موقتاً جایش بازی می‌کند و با برگشتن، صندلی‌اش را پس می‌گیرد |

> در تست شبیه‌سازی (۲۰۰ بازی) ربات «سخت» در حکم ۹۷٪ از «آسان» و ۷۰٪ از «متوسط» برد؛ یعنی سطح‌ها واقعاً با هم فرق دارند.

## 📜 قوانین پیاده‌سازی‌شده

### حکم
- ۴ بازیکن، دو تیم؛ یارها روبه‌روی هم (صندلی ۰ و ۲ در برابر ۱ و ۳). نوبت پادساعتگرد.
- **تعیین حاکم:** دست اول کارت‌ها رو به بالا پخش می‌شود تا اولین آس (با انیمیشن).
- حاکم **۵ کارت اول** را می‌بیند و **حکم** را اعلام می‌کند؛ بعد ۴+۴ کارت پخش می‌شود.
- **پیروی اجباری از خال**؛ بُر زدن فقط وقتی آن خال را نداری (سرور هم کنترل می‌کند).
- امتیاز: ۷ دست = **۱** | کُت (۷ به ۰) = **۲** | شلم (۱۳ دست) = **۳**.
  وقتی تیمی ۷ به ۰ جلو باشد، بازی ادامه می‌یابد: اگر حریف یک دست بگیرد کُت قطعی است، اگر نه شلم.
- اگر تیم حاکم ببازد، حاکمی به نفر بعدی می‌رسد. پایان بازی: ۳ / ۵ / ۷ امتیاز (قابل انتخاب).

### شلم
- ۱۲ کارت برای هر نفر + ۴ کارت وسط (خاک). پخش‌کننده هر دور می‌چرخد.
- **بید** از ۱۰۰ تا ۱۶۵ با گام ۵؛ پاس = خروج از بید. اگر همه پاس دهند دوباره پخش می‌شود.
- حاکم ۴ کارت وسط را برمی‌دارد، ۴ کارت دور می‌ریزد و حکم را اعلام می‌کند.
- آس و ده = ۱۰ | پنج = ۵ | هر دست = ۵ ← ۱۰۰ + ۱۲×۵ + خاک ۵ = **۱۶۵**
- کارت‌های دورریخته و ۵ امتیازش مال تیم حاکم.
- رسیدن به بید: هر تیم امتیاز خودش | نرسیدن: تیم حاکم **منفیِ بید** و حریف امتیاز خودش.
- **شلم کامل** (همه ۱۲ دست): **۳۳۰+** | اعلام شلم (بید ۱۶۵) و نرسیدن: **۳۳۰−**
- پایان بازی: ۶۰۰ یا ۱۱۶۵ امتیاز.

> اعداد ویژه (مثل ۳۳۰) بالای فایل `game/shelem.js` تعریف شده‌اند و اگر قانون محلی شما فرق دارد، راحت عوض می‌شوند.

## 💻 اجرای محلی (بدون تلگرام، داخل مرورگر)

پیش‌نیاز: **Node.js 18 یا بالاتر**

```bash
cd persian-cards
npm install
cp .env.example .env
```

فایل `.env` را برای تست محلی این‌طور تنظیم کنید:

```env
BOT_TOKEN=
PUBLIC_URL=
BOT_MODE=polling
ALLOW_DEV_LOGIN=true
PORT=3000
```

```bash
npm run dev        # یا npm start
```

حالا `http://localhost:3000` را باز کنید. هر **تب مرورگر یک بازیکن مهمان جداست**؛ برای تست چندنفره در یک تب میز «با دوستان» بسازید و در تب دیگر کد میز را وارد کنید (یا آدرس `http://localhost:3000/?room=کدمیز`).

تست قوانین (بدون نیاز به سرور):
```bash
npm test
```

### تست داخل تلگرام روی کامپیوتر خودتان
تلگرام فقط آدرس **HTTPS** را برای مینی‌اپ قبول می‌کند. یک تونل بسازید:
```bash
npx cloudflared tunnel --url http://localhost:3000
# یا: ngrok http 3000
```
آدرس https ساخته‌شده را در `PUBLIC_URL` بگذارید، `BOT_TOKEN` را پر کنید و سرور را دوباره اجرا کنید.
⚠️ یک توکن نمی‌تواند هم‌زمان روی Render (webhook) و لوکال (polling) کار کند؛ موقع تست لوکال `BOT_MODE=polling` بگذارید و بعد از تست، سرویس Render را یک بار Restart کنید تا webhook دوباره ثبت شود.

## 🤖 ساخت ربات در BotFather

1. در تلگرام به [@BotFather](https://t.me/BotFather) بروید و `/newbot` را بزنید.
2. یک **نام** (مثلاً «میز ورق») و یک **یوزرنیم** که به `bot` ختم شود (مثلاً `MizVaraghBot`) بدهید.
3. **توکن** را کپی کنید (شبیه `1234567890:AAH...`). این همان `BOT_TOKEN` است. آن را به هیچ‌کس ندهید.
4. (اختیاری) زیباسازی:
   - `/setdescription` ← «حکم و شلم آنلاین با دوستان و ربات‌ها 🃏»
   - `/setabouttext` و `/setuserpic` برای توضیح کوتاه و عکس پروفایل

> دستورهای ربات (`/start`, `/play`, `/help`) و **Menu Button** را خود سرور بعد از اجرا به‌صورت خودکار تنظیم می‌کند.

## ☁️ دیپلوی رایگان روی Render (قدم‌به‌قدم)

### ۱) کد را روی GitHub بگذارید
```bash
cd persian-cards
git init
git add .
git commit -m "Persian cards mini app"
git branch -M main
git remote add origin https://github.com/USERNAME/persian-cards.git
git push -u origin main
```
(فایل `.env` به‌خاطر `.gitignore` آپلود نمی‌شود، که درست است.)

### ۲) ساخت سرویس در Render
**روش الف: Blueprint (سریع‌تر)**
1. در [dashboard.render.com](https://dashboard.render.com) روی **New → Blueprint** بزنید.
2. ریپازیتوری را انتخاب کنید؛ Render فایل `render.yaml` را می‌خواند.
3. مقدار `BOT_TOKEN` را وارد کنید. `APP_SHORT_NAME` را فعلاً خالی بگذارید (در مرحله ۴ پر می‌کنیم).
4. **Apply** را بزنید.

**روش ب: دستی**
1. **New → Web Service** ← ریپازیتوری را وصل کنید.
2. تنظیمات:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
   - (Advanced) Health Check Path: `/health`
3. **Create Web Service**.

### ۳) متغیرهای محیطی (Environment)
در صفحه سرویس ← تب **Environment** ← **Add Environment Variable**:

| کلید | مقدار | توضیح |
|---|---|---|
| `BOT_TOKEN` | توکن BotFather | الزامی |
| `BOT_MODE` | `webhook` | روی Render حتماً webhook |
| `ALLOW_DEV_LOGIN` | `false` | فقط کاربران واقعی تلگرام وارد شوند |
| `APP_SHORT_NAME` | مثلاً `play` | بعد از مرحله ۴؛ برای لینک دعوت مستقیم |
| `PUBLIC_URL` | (خالی) | لازم نیست؛ Render خودش `RENDER_EXTERNAL_URL` را می‌دهد |
| `NODE_VERSION` | `20` | اختیاری |

بعد از ذخیره، سرویس دوباره دیپلوی می‌شود. در **Logs** باید ببینید:
```
🃏 سرور روی پورت 10000 اجرا شد → https://persian-cards-xxxx.onrender.com
🤖 @YourBot در حالت webhook فعال شد
```
آدرس سرویس (مثلاً `https://persian-cards-xxxx.onrender.com`) را کپی کنید. با باز کردن `.../health` باید `{"ok":true,...}` ببینید.

### ۴) ساخت Mini App در BotFather (برای لینک دعوت مستقیم)
1. در BotFather: `/newapp` ← ربات‌تان را انتخاب کنید.
2. **Title:** میز ورق
3. **Description:** حکم و شلم آنلاین
4. **Photo:** یک عکس ۶۴۰×۳۶۰ پیکسل بفرستید.
5. **GIF:** `/empty` بفرستید.
6. **Web App URL:** آدرس Render (`https://persian-cards-xxxx.onrender.com`)
7. **Short name:** مثلاً `play`
8. BotFather لینکی مثل `https://t.me/YourBot/play` می‌دهد.
9. در Render، `APP_SHORT_NAME=play` را اضافه کنید و ذخیره کنید.

(اختیاری) در BotFather ← `/mybots` ← ربات ← **Bot Settings → Configure Mini App** ← Enable، تا دکمه «Open App» روی پروفایل ربات هم بیاید.

### ۵) Menu Button
سرور هنگام اجرا خودکار دکمه منو «🎴 بازی» را روی مینی‌اپ تنظیم می‌کند. اگر خواستید دستی تنظیم کنید:
`/mybots` ← ربات ← **Bot Settings → Menu Button → Configure menu button** ← آدرس Render ← عنوان «🎴 بازی».

### ۶) تست
1. ربات را باز کنید، `/start` بزنید ← منوی «بازی حکم / بازی شلم / باز کردن میز ورق» می‌آید.
2. هر دکمه، مینی‌اپ را **مستقیم داخل تلگرام** باز می‌کند (دکمه‌های حکم/شلم مستقیم پنل ساخت همان بازی را باز می‌کنند).
3. دکمه Menu کنار کادر پیام هم مینی‌اپ را باز می‌کند.

## 🔗 تست لینک دعوت

1. داخل مینی‌اپ یک بازی را انتخاب کنید ← **«👥 با دوستان»** ← **ساخت میز**.
2. در لابی روی **«📨 دعوت دوستان در تلگرام»** بزنید و برای یک دوست (یا حساب دوم خودتان) بفرستید. یا روی کد میز بزنید تا لینک کپی شود.
3. لینک‌ها:
   - با `APP_SHORT_NAME`: `https://t.me/YourBot/play?startapp=ABC123` ← مینی‌اپ **مستقیم** باز می‌شود و کاربر **خودکار وارد همان میز** می‌شود.
   - بدون آن: `https://t.me/YourBot?start=join_ABC123` ← ربات پیام «به میز دعوت شدی» با دکمه **ورود به میز** می‌فرستد.
4. دوست شما در لابی ظاهر می‌شود. هر کس می‌تواند با «بنشین» صندلی/تیمش را عوض کند. میزبان جاهای خالی را با ربات پر می‌کند و **شروع بازی** را می‌زند.
5. تست اتصال مجدد: وسط بازی مینی‌اپ را ببندید و دوباره باز کنید؛ به همان میز و همان صندلی برمی‌گردید.

(اختیاری) دعوت inline: در BotFather `/setinline` را فعال کنید؛ بعد در هر چتی بنویسید `@YourBot ABC123` تا کارت دعوت با دکمه ورود ساخته شود.

## ⚠️ نکات نسخه رایگان Render
- سرویس رایگان بعد از **۱۵ دقیقه بدون ترافیک می‌خوابد** و اولین درخواست بعدی حدود ۳۰ تا ۶۰ ثانیه طول می‌کشد. پیام ربات (webhook) سرویس را بیدار می‌کند؛ تلگرام اگر جواب دیر برسد دوباره تلاش می‌کند.
- برای همیشه بیدار ماندن، می‌توانید با [UptimeRobot](https://uptimerobot.com) هر ۱۰ دقیقه آدرس `/health` را پینگ کنید (۷۵۰ ساعت رایگان ماهانه برای یک سرویس شبانه‌روزی کافی است).
- میزها در حافظه سرور نگه داشته می‌شوند؛ با هر دیپلوی جدید یا خوابیدن سرویس، میزهای فعال پاک می‌شوند (تا وقتی کسی آنلاین است، اتصال WebSocket سرویس را بیدار نگه می‌دارد).
- میزهایی که ۱۵ دقیقه هیچ بازیکن آنلاینی نداشته باشند خودکار پاک می‌شوند.

## 🛠️ عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «لطفاً بازی را از داخل تلگرام باز کنید» | آدرس را مستقیم در مرورگر باز کرده‌اید و `ALLOW_DEV_LOGIN=false` است. از داخل ربات باز کنید. |
| ربات جواب نمی‌دهد | Logs را ببینید؛ `BOT_TOKEN` درست است؟ آیا هم‌زمان جای دیگری با polling اجرا شده؟ سرویس را Restart کنید. |
| دکمه‌های مینی‌اپ در /start نیستند | آدرس عمومی HTTPS نیست. روی Render خودکار درست است؛ لوکال از تونل استفاده کنید. |
| لینک دعوت ربات را باز می‌کند نه مینی‌اپ را | `APP_SHORT_NAME` را دقیقاً برابر Short name در `/newapp` بگذارید. |
| صدا پخش نمی‌شود | مرورگرها صدا را بعد از اولین لمس فعال می‌کنند؛ یک بار صفحه را لمس کنید. تنظیمات ⚙️ را هم چک کنید. |
| «میز پیدا نشد» | سرور ری‌استارت شده یا میز منقضی شده؛ میز جدید بسازید. |

## 🔒 امنیت
- هویت کاربر با **امضای HMAC روی initData** تلگرام در سرور بررسی می‌شود؛ کسی نمی‌تواند خودش را جای دیگری جا بزند.
- همه قوانین (نوبت، پیروی از خال، بید، دور ریختن) **سمت سرور** کنترل می‌شوند؛ کلاینت فقط نمایش است و دست بقیه به کلاینت ارسال نمی‌شود.
- بُر زدن با `crypto.randomInt` انجام می‌شود.
- مسیر webhook با یک مسیر مخفی و `secret_token` محافظت شده است.
- محدودیت نرخ پیام روی WebSocket برای جلوگیری از اسپم.
